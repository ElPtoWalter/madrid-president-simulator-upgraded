# Madrid President Simulator — Expanded Market

Proyecto fan no oficial para montar el once del Real Madrid, vender jugadores, fichar objetivos, seguir rumores y exportar tu proyecto.

## Novedades de esta versión

- Plantilla revisada con la lista oficial provisional del Real Madrid.
- Quitados Modrić, Carvajal, Ceballos, Alaba y Fran García del grupo activo; algunos aparecen como salidas recientes.
- Añadidos Cucurella, Dumfries, Konaté, Bernardo Silva, Carreras, Huijsen y cantera/rotación relevante.
- Mercado ampliado con una lista grande de objetivos por posición: porteros, laterales, centrales, pivotes, interiores, mediapuntas, extremos y delanteros.
- Rumores separados de fichajes confirmados.
- `data.json` preparado para actualizar plantilla/rumores sin tocar el código.
- GitHub Actions preparado como esqueleto para actualización automática. Para conectar X/Fabrizio se necesita API oficial de X y un token propio.

## Publicación en GitHub Pages

Sube estos archivos a la raíz del repositorio:

- `index.html`
- `styles.css`
- `app.js`
- `data.json`
- `README.md`
- carpeta `.github`
- carpeta `scripts`

Después haz commit y push.

## Aviso legal

Proyecto fan no oficial. No afiliado al Real Madrid, Transfermarkt ni ninguna entidad oficial. Los valores, rumores e imágenes son orientativos/editables.
