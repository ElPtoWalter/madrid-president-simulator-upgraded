# Madrid President Simulator 5.0 · AutoScout Intelligence

Proyecto fan no oficial inspirado en el Real Madrid. Versión centrada en la temporada 2026/27 con José Mourinho como entrenador y enfoque de planificación realista: plantilla, ventas, compras, presupuesto, Reality Score, análisis táctico, AutoScout y rumores automáticos.

## Novedades 5.0

- Base ampliada a más de 300 jugadores.
- Nuevo tab **Intelligence**.
- Centro de mando ejecutivo.
- Auditoría avanzada de plantilla.
- Top oportunidades con score automático.
- Plan 100M, plan realista y plan de salidas.
- AutoScout Intelligence 5.0 preparado para leer más fuentes deportivas.
- Rumores automáticos con creación de candidatos fichables si el jugador no existe.
- Fotos: tarjeta local inmediata + foto real desde Wikimedia cuando esté disponible.
- AutoScout no debería dejar jugadores sin imagen.

## Archivos a subir en GitHub web

Sube o reemplaza estos archivos:

- `index.html`
- `styles.css`
- `app.js`
- `data.json`
- `README.md`
- `scripts/update-data.mjs`

No subas `.github/` si ya tienes creado el workflow.

## Después de subir

1. Espera a que GitHub Pages despliegue.
2. Abre la web con `?v=5-autoscout-intelligence`.
3. Pulsa `Ctrl + F5`.
4. Ejecuta `Actions → AutoMarket update → Run workflow` para probar AutoScout.

## Aviso

No es una web oficial. No está afiliada al Real Madrid, Transfermarkt, X ni medios deportivos. Los valores son orientativos y editables por el usuario.
